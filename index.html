Production RAG

Retrieval that finds the right document

A multi-tenant RAG microservice live on client staff portals in travel and insurance, with per-client, per-use-case prompt and model configs.

  • Accuracy 82.4% → 95.6%, tokens down 66-72%
  • LLM query stage that corrects, splits and routes questions
  • Off-topic questions refused 24 of 24 times
Retrieval R&D

Benchmarks, not guesses

Compared S3 Vectors, OpenSearch and pgvector hybrid search, chunk sizes and reranker pools with recall and LLM-as-judge metrics.

  • Picked the lowest-cost backend at equal quality
  • Ingestion-time LLM classifier: new knowledge bases with zero code changes
  • Evaluated self-hosted gpt-oss-20b on vLLM
Agentic Systems

Agents with guardrails

A multi-tenant platform for multi-agent workflows on Orkes Conductor with Bedrock tool calling and MCP tool servers.

  • Database-driven guardrails: kill switch, RBAC, rate limits
  • Per-call cost tracking on every billable LLM call
  • LLM failure triage and daily AI-generated ops reports
